# Week 2 Evidence

## What was completed

Week 2 created the initial Android application shell and navigation. The main screen links to Scan, Result, History, Disease Library, Settings, and Analytics screens. Most destination screens are placeholders for later development.

## Evidence

The `Images/` folder contains screenshots of the main screen and each available destination screen: `Main.png`, `Scan.png`, `Result.png`, `History.png`, `Disease.png`, `Settings.png`, and `Analytics.png`.

## How to test

1. Open `android-app-kotlin/` in Android Studio.
2. Run the `app` configuration on an emulator or Android device.
3. Tap each button on the main screen.
4. Confirm that every button opens the matching screen shown in `Images/` and the app does not crash.

The screenshots verify the screen structure and navigation, not completed prediction, history, library, or analytics features.
